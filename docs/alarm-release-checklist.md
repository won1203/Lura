# 알람 출시 전 실제 기기 점검표

각 항목은 알람을 현재 시각에서 3~5분 뒤로 설정해 확인한다.

## 기본 동작

- [ ] 수면 음원 재생 중 기상 시각에 알람이 울린다.
- [ ] 수면 음원 일시정지 상태에서도 기상 시각에 알람이 울린다.
- [ ] 수면 음원을 수동 종료해도 기상 시각에 알람이 울린다.
- [ ] 앱 화면을 닫고 화면을 잠가도 알람이 울린다.
- [ ] 기상 시 수면 음원 알림이 제거된다.
- [ ] 알람 끄기와 5분 뒤 다시 알림이 각각 동작한다.

## 복구 동작

- [ ] 알람 설정 후 휴대폰을 재부팅해도 예약 시각에 알람이 울린다.
- [ ] 알람 설정 후 앱을 업데이트해도 예약이 유지된다.
- [ ] 휴대폰 시간을 변경하면 새 현지 시각 기준으로 알람이 다시 예약된다.
- [ ] 휴대폰 시간대를 변경하면 새 시간대 기준으로 알람이 다시 예약된다.

## 권한과 제조사 절전

- [ ] 알림 권한을 거부하면 앱이 설정 이동 안내를 표시한다.
- [ ] 전체 화면 알람 권한을 거부하면 앱이 설정 이동 안내를 표시한다.
- [ ] 삼성 배터리 절전 상태에서도 알람음이 울린다.
- [ ] Android 13, 14, 15, 16 기기에서 잠금 화면 알람을 확인한다.

## 기록

- [ ] 정상 기상 후 해당 날짜가 수면 리포트에 기록된다.
- [ ] 음원을 수동 종료한 경우 취소된 세션이 완료 기록으로 잘못 집계되지 않는다.
- [ ] 앱 프로세스가 종료된 뒤 기상 알람이 울려도 수면 기록이 완료 처리된다.
